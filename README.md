# 🎰 Projeto MegaUna - Sistema de Sorteios

Este projeto foi desenvolvido como parte do módulo de **Java Avançado** no SENAI. O objetivo é simular um sistema de apostas e sorteios, aplicando conceitos de lógica de programação e POO.

## 🛠️ Tecnologias e Conceitos
- **Linguagem:** Java 17+
- **Paradigma:** Programação Orientada a Objetos (POO)
- **Estruturas de Dados:** Manipulação de Listas e Coleções
- **Algoritmos:** Lógica de sorteio e validação de apostas

## 🚀 Próximos Passos
Este projeto servirá de base para a implementação de uma **API RESTful** utilizando **Spring Boot**, integrando persistência de dados com **PostgreSQL** e conteinerização com **Docker**.
